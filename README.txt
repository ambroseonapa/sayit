SayIt – speak into any text box (Chrome extension, version 0.4)
================================================================

UPDATING (keeps your key and settings)
Copy these files over the ones in your SayIt folder, then click the reload arrow on SayIt in chrome://extensions.
Also reload any open tab you want to use it in.

INSTALL
1. Unzip this folder somewhere you won't delete it (e.g. Documents/SayIt).
2. In Chrome, open chrome://extensions and turn on "Developer mode" (top right).
3. Click "Load unpacked" and choose the SayIt folder (the one with manifest.json inside).
4. Pin SayIt from the puzzle-piece icon.

SET UP FOR BEST RESULTS (5 minutes, free)
1. Go to console.groq.com/keys, sign in with Google, click "Create API key", copy it.
2. In SayIt settings, choose AI provider "Groq", paste the key, press "Test speed".
3. In Speech, choose "Most accurate (Whisper)" if Chrome mishears you, and add your names and special words.

USE
- Click inside any text box, tap the mic icon (or Alt+Shift+S), speak, press Done.
- Grammar is fixed while you talk, so the text appears almost straight away.
- A− / A+ on the box change its size. Esc cancels.
- After it inserts: "Use my exact words" or "Undo".

KNOWN LIMITS
- Won't run on chrome:// pages or the Chrome Web Store.
- Google Docs works (new in 0.4). If it ever fails there, SayIt copies the text so you can press Ctrl+V.
